# Analisis and figures data 

Data used for the statistical analisis and figures in the paper  
"Satellite mapping reveals extensive industrial activity at sea"  
by Global Fishing Watch et al. (2024, Nature).

See the paper Methods for a detailed description of our data analysis, and the
public code repository for the scripts that generated and used these data files.

Paper <https://www.nature.com/articles/s41586-023-06825-8>

Code <https://github.com/GlobalFishingWatch/paper-industrial-activity>


## Vessel detections

### `industrial_vessels_v20240102.csv`

Data file (1.5 GB) containing detections that are likely vessels from 2017 to
2021, detected using Sentinel-1 SAR imagery, classified using deep learning and
matched to AIS.

Fields:
- scene_id: Original scene id of the Sentinel-1 image
- timestamp: Time of the Sentinel-1 acquisition
- lat: Latitude of the detection
- lon: Longitude of the detection
- length_m: Length of the vessel in meters estimated with a neural net model
- mmsi: MMSI number from AIS of the vessel that matched to the SAR detection
- matching_score The strength of the vessel’s match to the SAR detection. See
  Methods of Paolo e al. (2024) for description
- fishing_score: Likelihood that a detection is a fishing vessel, on a scale
  from 0 to 1, based on a neural net model that knows the object’s size and
  location in the water
- matched_category: String with one of the four categories: “unmatched” if it
  was not matched to a vessel broadcasting AIS, “matched_fishing” if it was
  matched to a vessel broadcasting AIS and was identified as a fishing vessel,
  “matched_nonfishing” if it was matched to a vessel broadcasting AIS and was
  identified as a non-fishing vessel, “matched_unknown” if it was matched to a
  vessel broadcasting AIS and its identity was unknown
- overpasses_2017_2021: Number of Sentinel-1 images taken on the detection’s
  location (gridded at a 200th of a degree) from 2017 to 2021

### `raster_5th_degree.feather`

Data file (10 MB) generated by the script
CreateVesselActivityRasterDataframe.py. It produces a gridded output, at 1/5th
of a degree, of estimated activity of fishing and non-fishing vessels from
Sentinel-1, and it is used to create Figure 1. Lat_index and lon_index are the
latitude and longitude, multiplied times five, of the southwest corner of each
gridcell. The number of detections of fishing and non-fishing vessels are
calculated by counting the number of detections in the grid cell and then
dividing by the number of images taken of that grid cell between 2017 and 2021.

Fields:
- lat_index: integer, 5 times the latitude of the southwest corner of the grid
  cell
- lon_index: integer, 5 times the longitude of the southwest corner of the grid
  cell
- matched_fishing: Number of detections matched to fishing vessels with AIS
  within this grid cell, divided by the number of Sentinel-1 images of this part
  of the ocean.
- matched_nonfishing: Normalized number of detections matched to non-fishing
  vessels with AIS within this grid cell, divided by the number of Sentinel-1
  images of this part of the ocean.
- matched_unknown_likelyfish: Normalized number of detections matched vessels
  with AIS that we don’t know the identity of based on the AIS database, but
  which the fishing model thinks are likely fishing vessels.
- matched_unknown_likelynonfish: Normalized number of detections matched vessels
  with AIS that we don’t know the identity of based on the AIS database, but
  which the fishing model thinks are likely non-fishing vessels.
- dark_fishing: unmatched detections that are fishing, based on the model. Note
  that if the model gives a detection a 0.7 likelihood that it is a fishing
  vessel, that detection will count toward 0.7 fishing vessels.
- dark_nonfishing: dark_fishing: unmatched detections that are non-fishing,
  based on the model.
- overpasses_2017_2021: average number of times that this cell was imaged by
  Sentinel-1 from 2017 to 2021
- detections: normalized total number of detections in this cell
- AIS_fishing: matched_fishing + matched_unknown_likelyfish
- AIS_nonfishing: matched_nonfishing + matched_unknown_likelyfish
- tot_fishing: AIS_fishing + dark_fishing
- tot_nonfishing: AIS_nonfishing + dark_nonfishing

### `vessels_bycontinent_v20230803.csv

  satellite overpass.


## Vessel traffic

### `infra_vessel_activity_oil_100th_degree_v20230222.zip`

Data archive (623 MB) containing partitioned CSV files that together form
gridded activity by vessel class that interacted with oil infrastructure in
2021. An interaction is defined as an event where a vessel is within 200 meters
of an oil related structure for at least 2 hours at a speed of 0 knots. It is
used in the script VesselBarplots.py and Figure 4.

Fields:
- lat_index: Latitude binned at 100th degree.
- lon_index: Longitude binned at 100th degree.
- visit_hours_sum: Total hours spent in the cell by vessels that interacted with
  offshore oil infrastructure in 2021.
- best_class: Best known vessel class.
- total_hours: total hours spent in the cell by all vessels in 2021

### `infra_vessel_activity_wind_100th_degree_v20230222.csv`

Data file (119 MB) containing the gridded activity by vessel class that
interacted with wind infrastructure in 2021. An interaction is defined as an
event where a vessel is within 200 meters of a wind related structure for at
least 2 hours at a speed of 0 knots. It is used in the script VesselBarplots.py
and Figure 4.

Fields:
- lat_index: Latitude binned at 100th degree.
- lon_index: Longitude binned at 100th degree.
- visit_hours_sum: Total hours spent in the cell by vessels that interacted with
  offshore wind infrastructure in 2021.
- best_class: Best known vessel class.
- total_hours: Total hours spent in the cell by all vessels in 2021


## Vessel time series

### `24day_rolling_augmented_v20230816.csv`

Data file (67 MB) containing the average number of detections by EEZ in a 24-day
rolling average. 24 days was chosen because it is twice the cycle of Sentinel-1,
which has a 12-day revisit time, and this time period minimized the number of
positions that we had to interpolate. This time series was calculated at a 200th
of a degree, and then averaged across the EEZ. When a grid cell had no images
for a given 24 day period, the number of detections was interpolated using the
    previous and future grid cell. Very few (~0.7%) of the total detections are
    interpolated. This is generated by 24DayAugmented.py and used in Figure 3.

Fields:
- rolling_date: date at the middle of a 24 day period
- eez_iso3: iso3 value of the EEZ that the detection is within, drawing on the
  values from Marine Regions v11.
- ais_fishing: Normalized number of detections that were matched to fishing
  vessels with AIS.
- dark_fishing: Normalized number of unmatched detections that the model
  predicted to be fishing.
- ais_nonfishing: Normalized number of detections that were matched to
  non-fishing vessels with AIS.
- dark_nonfishing: Normalized number of unmatched detections that the model
  predicted to be fishing.
- ais_nonfishing100: AIS non-fishing vessels that matched to SAR detections
  larger than 100 meters.
- dark_nonfishing100: Non-broadcasting non-fishing vessels larger than 100
  meters.
- ais_fishing_i: same as ais_fishing, but interpolated values for cells that had
  no overpasses in that 24-day period. All following fields with “_i” following
  them represent such interpolated values.
- ais_nonfishing_i
- dark_fishing_i
- dark_nonfishing_i
- ais_nonfishing100_i
- dark_nonfishing100_i
- year: year of detection
- detections: total number of detections
- fishing: total number of fishing detections
- nonfishing: total number of non-fishing detections
- nonfishing100: total number of non-fishing detections larger than 100m


## Infrastructure detections

### `offshore_infrastructure_v20231106.csv.zip`

Data file (11.4 MB) containing detections that are likely offshore
infrastructure from 2017 to 2021 (monthly), detected using Sentinel-1 SAR
imagery and classified using deep learning (based on SAR and optical images).

Fields:
- structure_id: Unique identifier for all detections of the same structure
- composite_date: Center date of the six-month image composite used for
  detection. Infrastructure is detected once a month on a median image
  composite (see Paolo et al., 2024)
- lat: Latitude of the structure
- lon: Longitude of the structure
- label: String with one of the following classes: “oil” / “probable_oil” /
  “possible_oil” - likely an oil platform with high / medium / low confidence;
  “wind” / “probable_wind” / “possible_wind” - likely a wind turbine with high
  / medium / low confidence; “lake_maracaibo” - likely an oil structure in Lake
  Maracaibo Venezuela; “unknown” - likely other human-made structure

### `infra_global_time_series_v20230816.csv`

Data file (2 KB) containing time series for global offshore infrastructure.
These data are used in Figure 4.

Fields:
- detect_date: midpoint of the 6-month composite of the detection
- oil: count of oil detections
- probable_oil: count of probable oil detections
- possible_oil: count of possible oil detections
- other: count of other detections
- wind: count of wind detections
- oil_other: count of oil + other detections

### `infra_eez_time_series_v20230816.csv`

Data file (206 KB) containing time series for global offshore infrastructure
grouped by EEZ. These data are used in Figure 4.

Fields:
- detect_date: midpoint of the 6-month composite of the detection
- oil: count of oil detections
- probable_oil: count of probable oil detections
- possible_oil: count of possible oil detections
- other: count of other detections
- wind: count of wind detections
- oil_other: count of oil + other detections
- iso3: EEZ

### `offshore_infra_reclassified_w_regions_v20230816.csv`

Data file (1.7 MB) containing infrastructure detections used to generate the
global map in Figure 4.

Fields:
- id: detection id
- lon: longitude
- lat: latitude
- label: predicted infrastructure class
- inside_oil_polygon: boolean; whether the detection is within an oil production
  area
- oil_region: regional oil production area

### `infra_barplot_oil_v20230816.csv`

Data file (1 KB) containing median values of monthly counts of offshore oil
infrastructure by EEZ in 2021, and is used to generate Extended Data Figure 9.
It is used by the script InfraBarplots.py.

Fields:
- country_name: EEZ
- oil_count_median: Median monthly count of “oil” in 2021.
- probable_oil_count_median: Median monthly count of ‘probable oil’ in 2021.

### `infra_barplot_wind_v20230816.csv`

Data file (354 B) containing median values of monthly counts of offshore wind
infrastructure by EEZ in 2021, and is used to generate Extended Data Figure 9.
It is used by the script InfraBarplots.py

Fields:
- country_name: EEZ
- wind_count_median: Median monthly count of ‘wind’ in 2021.
- probable_wind_count_median: Median monthly count of ‘‘probable wind’ in 2021.


## Distance from infra and shore

### `fishing_dist_from_infra.feather`

Data file (102 KB) containing the normalized relative amount of activity by
vessel type as a function of distance from infrastructure detections , and is
used to generate Extended Data Figure 10.

Fields:
- geartype: vessel type
- label: infrastructure class prediction
- distance_m: distance from infrastructure in meters
- normalized_fishing_activity: normalized relative amount of activity

### `distance_from_shore_vessel.feather`

Data file (90 KB) containing the average number of matched and unmatched vessels
per day as a function of distance from shore, and is used to generate Extended
Data Figure 10.

Fields:
- distance_From_shore_km: distance from shore in km
- matched_fishing: average number of fishing vessels matched to AIS per day
- matched_nonfishing: average number of non-fishing vessels matched to AIS per
  day
- matched_unknown: average number of unknown type vessels matched to AIS per day
- matched_unknown_likelyfish: average number of likely fishing vessels matched
  to AIS per day
- matched_unknown_likelynonfish: average number of likely non-fishing vessels
  matched to AIS per day
- Unmatched_fishing: average number of fishing vessels unmatched to AIS per day
- Unmatched_nonfishing: average number of non-fishing vessels unmatched to AIS
  per day
- detections: average number of SAR detections per day
- AIS fishing: average number of AIS fishing vessels per day
- AIS non-fishing: average number of AIS non-fishing vessels per day
- dark fishing: average number of dark fishing vessels per day
- dark non-fishing: average number of dark non-fishing vessels per day
- tot_fishing: average total number of fishing vessels per day
- tot_nonfishing: average total number of non-fishing vessels per day

### `distance_from_shore_infra.feather`

Data file (5 KB) containing the average number of infrastructure detections by
class per day as a function of distance from shore, and is used to generate
Extended Data Figure 10.

Fields:
- distance_From_shore_km: infrastructure detection distance from shore in km
- oil: average number of oil detections per day
- other: average number of other detections per day
- wind: average number of wind detections per day
